# Arduino Multi Tester

An Arduino-based multi-purpose electronics testing project.

The project is being developed step by step, with the code organized into separate `.h` and `.cpp` files for easier development and maintenance.

## Project Structure

```text
Arduino-Multi-Tester/
├── Arduino-Multi-Tester.ino
├── config.h
├── display.h
├── display.cpp
├── menu.h
├── menu.cpp
└── Other module files
```

## Development

* Platform: Arduino IDE
* Microcontroller: Arduino
* Display: SSD1306 OLED 128×64
* I²C Address: `0x3C`

The project is under active development. Features and code structure may change as development continues.
